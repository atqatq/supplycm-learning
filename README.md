# supplycm-learning

Simple lessons that teach supply chain management using the [supplycm](https://github.com/atqatq/supplycm) Python package.

## What is this?

A collection of easy-to-follow lessons that explain supply chain ideas in plain English. Each lesson uses real examples and shows you how to use the supplycm package to solve real problems.

## Who is this for?

- Students learning about supply chains for the first time
- People who want to use the supplycm package but need to understand the ideas first
- Anyone who likes learning by doing

## How to use these lessons

1. Start with Module 1 (What is a Supply Chain?)
2. Read each lesson in order
3. Try the code examples on your computer
4. Check your understanding with the quizzes
5. Do the exercises to practice

## The Algorithm Library

We are writing a plain-English page for EVERY algorithm in the
[supplycm package](https://github.com/atqatq/supplycm). Over 200 pages are
already done: the full forecasting toolbox, the complete inventory library,
supplier analytics, MRP, scheduling, quality, lean, S&OP, and more. Each page
has a runnable example, three self-check questions, and a challenge.

Browse the library: [algorithms/](algorithms/README.md) - track your progress
with the [tracker](progress/ALGORITHM_TRACKER.md). A full six-month guided
program is taking shape in [SIX_MONTH_PLAN.md](SIX_MONTH_PLAN.md).

## Prerequisites

- A computer with Python installed
- Basic Python knowledge (variables, lists, functions)
- The supplycm package installed: `pip install supplycm`
