# Traceability & Blockchain (4 algorithms)

Prove where a product has been, record by record.

**Levels:** 1 beginner · 3 intermediate · 0 advanced. Every page follows the same rhythm: plain English, a runnable example, a "check yourself" recall test, and a small challenge. No math beyond +, -, ×, ÷.

Read top to bottom the first time - the order goes from easiest to hardest.

| # | Algorithm | Level | One-line idea |
|---|-----------|-------|---------------|
| 1 | [Hash Chain](hash_chain.md) | Intermediate | A chain of digital fingerprints: each event's fingerprint includes the PREVIOUS event's fingerprint, so every record is welded to the one before |
| 2 | [Chain Verification](verify_chain.md) | Intermediate | The audit half of the hash chain: recompute every fingerprint from the records and compare with the stored chain |
| 3 | [Provenance Tracking](provenance_tracking.md) | Beginner | One product's complete life story, extracted from the stream of all supply chain events: harvested here, shipped there, stored there, sold there |
| 4 | [Smart Contract Check](smart_contract_check.md) | Intermediate | Rules that enforce themselves: temperature below 8, delivery before Friday, quantity within tolerance - this validates any transaction against the rule list and returns pass or explicit violations |
