# IoT & Sensors (4 algorithms)

Turn sensor data into live inventory and alerts.

**Levels:** 1 beginner · 3 intermediate · 0 advanced. Every page follows the same rhythm: plain English, a runnable example, a "check yourself" recall test, and a small challenge. No math beyond +, -, ×, ÷.

Read top to bottom the first time - the order goes from easiest to hardest.

| # | Algorithm | Level | One-line idea |
|---|-----------|-------|---------------|
| 1 | [Sensor Data Smoothing](sensor_data_smoothing.md) | Beginner | Raw sensor readings jitter - a temperature of 21.3, 21.4, 25.0, 21.2 is probably not a heat wave |
| 2 | [IoT Anomaly Detection](anomaly_detection.md) | Intermediate | This watches a live data stream and flags readings that stray far from the recent window's norm - measured in standard deviations |
