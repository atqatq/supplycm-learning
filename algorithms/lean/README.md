# Lean (4 algorithms)

Flow faster with takt time, OEE, and Little's Law.

**Levels:** 3 beginner · 1 intermediate · 0 advanced. Every page follows the same rhythm: plain English, a runnable example, a "check yourself" recall test, and a small challenge. No math beyond +, -, ×, ÷.

Read top to bottom the first time - the order goes from easiest to hardest.

| # | Algorithm | Level | One-line idea |
|---|-----------|-------|---------------|
| 1 | [Takt Time](takt_time.md) | Beginner | Takt time is the heartbeat your production must match: available work time divided by what the customer actually ordered |
| 2 | [OEE (Overall Equipment Effectiveness)](oee.md) | Beginner | OEE multiplies three questions: Was the machine running when needed (availability)? Did it run at full speed (performance)? Was the output good (quality)? Multiply the three percentages to get one 0-100% effectiveness score |
| 3 | [Cycle Time Efficiency (PCE)](cycle_time_efficiency.md) | Intermediate | Process cycle efficiency compares the time work is actually being transformed to the total time it waits around |
| 4 | [Little's Law: WIP](wip_calculation.md) | Beginner | Little's Law links three things you already know: WIP (work in progress) = throughput rate x flow time |
