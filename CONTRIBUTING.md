# Contributing to supplycm-learning

Thank you for your interest in improving these lessons.

## How You Can Help

### 1. Report Mistakes

Found a typo or error? Open an issue:
1. Go to the Issues tab
2. Click "New Issue"
3. Describe the mistake and where you found it

### 2. Suggest Improvements

Have an idea to make a lesson clearer?
1. Open an issue describing your suggestion
2. Explain what confused you and how to fix it

### 3. Add Examples

Want to add a real-world example?
1. Fork the repository
2. Add your example to the `examples/` folder
3. Open a pull request

### 4. Translate

Want to translate lessons to another language?
1. Create a folder for your language (e.g., `modules/es/` for Spanish)
2. Translate the files
3. Open a pull request

## Style Guide

When writing or editing lessons:

1. **Use simple language** - short words, short sentences
2. **Give real examples** - use food, toys, everyday items
3. **Include code** - show how to use supplycm
4. **Add quizzes** - help learners check understanding
5. **Use memory aids** - acronyms like DOWNTIME, FAST, ORDER
6. **No jargon** - or explain it immediately

## File Structure

```
modules/          - 12 learning modules
exercises/        - practice problems with answers
quizzes/          - self-test quizzes
examples/         - real-world examples
glossary.md       - term definitions
cheatsheet.md     - quick reference
FAQ.md            - frequently asked questions
```

## Pull Request Process

1. Fork the repo
2. Create a branch: `git checkout -b improve-module-3`
3. Make your changes
4. Commit with a clear message
5. Open a pull request
6. Respond to feedback
