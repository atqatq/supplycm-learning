# Course Planning Notes (internal)

Start date: January 2025.

## Mission

Build the free, complete supply chain course that uses the supplycm package:
plain English, runnable Python, active recall everywhere, no math beyond
basic arithmetic.

## Principles fixed on day one

1. **Plain English first.** Every concept gets an everyday analogy before any
   number appears.
2. **Active learning beats reading.** Every lesson must end with questions the
   learner answers from memory, plus a challenge they do themselves.
3. **Reinforcement is scheduled, not hoped for.** Flashcards, drills, and
   quizzes are part of the material, not an afterthought.
4. **One small business as the running case.** Learners apply each month's
   skills to their own cafe / shop / workshop.
5. **Basic arithmetic only.** If it needs more, we cut it or move it.

## The plan

- Phase 1 (done, see repo history): 12 core modules, exercises, quizzes,
  examples, glossary, cheatsheet, FAQ, notebooks, sub-lessons.
- Phase 2 (this year): the Algorithm Library - one plain-English page per
  supplycm algorithm (hundreds of them), organized by module, each with:
  - a runnable example (verified by executing it),
  - three self-check questions with hidden answers,
  - a "try this now" challenge,
  - links to the matching flashcards and drill.
- Phase 3: a full 6-month guided program with weekly checkpoints, growing out
  of the current 12-week plan. Draft first, finalize when the library lands.

## Lesson rhythm (every algorithm page follows it)

Read (2 min) -> Run the example (3 min) -> Recall: answer 3 questions (2 min)
-> Try the challenge (5 min) -> log it in the tracker.

## Quality bar

- Every code example is executed before publishing; the shown output is real.
- Every page states the exact import path.
- Difficulty is labeled (Beginner / Intermediate / Advanced).
- Anything needing more than basic arithmetic is rewritten or cut.
